# SHAYA Personal Brand Guidelines

Version 1.0 - Midnight Archive

## Brand idea

**Follow the evidence through the dark.**

SHAYA is a personal brand for careful technical work. It covers AI developer
tools, local model systems, security checks, benchmarks, and clear technical
documents.

The brand must feel calm, exact, curious, and trustworthy.

## Position

SHAYA turns uncertain technical systems into clear, tested results.

### Brand promise

Make complex work easier to inspect, understand, and trust.

### Audience

- Open-source developers
- AI tool builders
- Security-minded engineers
- Technical reviewers
- People who need evidence before they make a decision

### Brand attributes

- **Exact:** Claims use evidence.
- **Calm:** The design does not shout.
- **Curious:** The work looks beyond the first answer.
- **Practical:** Every idea must lead to a useful result.
- **Independent:** The voice is direct and has a clear point of view.

## Logo system

The primary mark has three parts:

1. The arch is the problem boundary.
2. The amber square is verified evidence.
3. The winding trace is the path from uncertainty to a clear result.

Use the full-color mark on dark backgrounds. Use the light mark on pale
backgrounds.

### Clear space

Keep clear space equal to one amber square on every side of the mark.

### Minimum size

- Digital mark: 24 px minimum
- GitHub avatar: 32 px minimum
- Printed mark: 8 mm minimum

### Do not

- Rotate the mark.
- stretch the mark.
- change the arch-to-trace ratio.
- add a glow or drop shadow.
- place the mark on a busy image without a solid field.
- use colors outside the approved palette.

## Color system

| Token | Hex | Primary use |
| --- | --- | --- |
| Void | `#071013` | Main background |
| Midnight | `#0E2231` | Secondary dark field |
| Archive | `#132B24` | Foliage and support color |
| Oxblood | `#7C2E20` | Doorways and restrained alerts |
| Trace | `#D58A25` | Evidence, paths, and key actions |
| Bone | `#E2D2B8` | Main text and logo arch |
| Smoke | `#6D7472` | Secondary text and rules |

Use Void, Midnight, and Archive for about 75 percent of a composition. Use Bone
for about 18 percent. Use Trace and Oxblood for no more than 7 percent.

Trace is the main signal color. Do not use it as a large background.

## Typography

### Display: Bahnschrift

Use Bahnschrift SemiCondensed or Bahnschrift SemiBold for titles, the wordmark,
and large labels.

- Use uppercase for short titles.
- Add moderate letter spacing.
- Keep one-line titles on one line.

### Body: Segoe UI

Use Segoe UI for body copy, captions, and explanations.

- Use short sentences.
- Use sentence case.
- Use regular or semibold weights.

### Technical: Cascadia Mono

Use Cascadia Mono for commands, tags, evidence labels, and small technical
details.

- Use it sparingly.
- Do not use it for long paragraphs.

## Illustration direction

Use dark editorial gouache, simple architecture, deep matte shadows, and one
controlled light source.

Approved subjects include:

- Doorways and arches
- Quiet work rooms
- Forest paths
- Stairs and thresholds
- Amber windows
- Books, maps, instruments, and evidence traces

Use flat perspective and clear silhouettes. Keep important detail visible in the
shadows.

Do not use:

- Generic robots or brains
- Purple AI gradients
- Code rain
- Busy dashboards
- Glossy 3D objects
- Random neon
- Horror imagery

## Voice

The SHAYA voice is calm, direct, and evidence-first.

### Write like this

- "The focused test passed on the current branch."
- "The result supports the component, not the full live system."
- "This is the smallest safe change."
- "The root cause is not confirmed."

### Do not write like this

- "This revolutionary solution changes everything."
- "The system is definitely fixed."
- "No issues exist."
- "We used cutting-edge AI to unlock value."

State the scope of every claim. Separate confirmed facts from inference.

## Tagline

Primary:

**TRACE WHAT OTHERS MISS.**

Optional supporting lines:

- Build. Verify. Explain.
- Evidence before confidence.
- Clear paths through difficult systems.

Use only one tagline in a composition.

## GitHub use

### Profile avatar

Use `assets/shaya-avatar-512.png`.

Keep the full rounded square. Do not crop the arch or trace.

### README banner

Use `assets/shaya-github-readme-banner-1600x600.png`.

Keep the banner at its original ratio. Do not add more text over it.

### Repository graphics

Use Void as the background, Bone for the title, and Trace for one important
label or path. Use Oxblood only for warnings or a doorway detail.

### README writing

Lead with the outcome. Then show scope, evidence, setup, and limits.
